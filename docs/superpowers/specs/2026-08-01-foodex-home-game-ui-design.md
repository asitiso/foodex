# Foodex 홈 게임 UI 개편 설계

## 목표

현재 홈 화면의 기능과 라우팅을 유지하면서, 참고 이미지처럼 첫눈에 게임으로 느껴지는 홈 화면으로 개편한다. 기능 추가보다 로고, 아이콘, 버튼, 배경과 UI의 결합감을 우선한다.

## 유지 범위

- 기존 홈 기능과 클릭 동작 유지
- 기존 데이터 구조와 게임 시스템 유지
- 기존 하단 내비게이션 동작 유지
- 모바일 한 화면 중심 구조 유지
- 배경 위 인터랙션 위치는 반응형으로 동작

## 구현 순서

### Step 1. 게임 로고

- 기존 텍스트 FOODEX를 독립된 게임 로고 컴포넌트로 교체
- 흰색 입체 글자, 보라 외곽선, 분홍·보라 하단 그림자, 금색 별 장식 적용
- PNG에 의존하지 않고 재사용 가능한 SVG/HTML 구조로 제작
- 홈 화면 폭에 맞춰 자동 축소

### Step 2. 주요 게임 아이콘

우선 교체 대상:

- 도감
- 모험
- 버디
- 식사 기록
- 상점
- 퀘스트

아이콘 규칙:

- 굵은 보라 외곽선
- 밝은 내부 색상
- 상단 하이라이트
- 하단 음영
- 둥근 장난감 형태
- 기존 클릭 영역과 접근성 레이블 유지

### Step 3. 버튼 외형 통일

세 가지 버튼 계층을 사용한다.

1. 건물 간판형: 도감, 모험, 버디
2. 메인 행동형: 식사 기록
3. 카드형: 하단 내비게이션 및 보조 메뉴

공통 규칙:

- 크림색 또는 채도 높은 내부색
- 진보라 외곽선
- 내부 흰색 하이라이트
- 아래쪽 입체 그림자
- 누를 때 실제로 내려가는 모션
- 최소 52px 터치 영역

### Step 4. 하단 내비게이션

- 기존 5개 탭의 동작과 DOM 순서 유지
- 각 탭을 독립된 게임 카드처럼 표현
- 선택 탭은 금색 테두리와 광택 강조
- 중앙 촬영 버튼은 크기만 강조하고 다른 탭과 겹치지 않게 유지

### Step 5. 배경과 버튼 결합

- 도감 버튼은 도감 건물 간판 위치
- 모험 버튼은 성 입구 위치
- 버디 버튼은 버디 건물 위치
- 식사 기록은 중앙 카메라 오브 위치
- 버튼은 화면 구석에 떠 있는 HUD가 아니라 배경 소품과 연결된 것처럼 배치

## 기술 구조

- `GameLogo`: 홈 전용 게임 로고
- `GameIcon`: 기존 아이콘 API는 유지하되 주요 아이콘에 채움형 게임 렌더링 추가
- `WorldHotspot`: 간판형 게임 버튼 스타일 담당
- `MealRecordOrb`: 메인 행동형 버튼 스타일 담당
- `BottomNav`: 카드형 내비게이션 스타일 담당
- 홈 전용 스타일 파일을 마지막에 로드해 다른 화면에 영향이 없도록 격리

## 반응형 기준

검증 화면:

- 375×667
- 390×844
- 430×932

각 화면에서 다음을 확인한다.

- 로고가 코인바와 겹치지 않음
- 캐릭터가 중앙 광장을 벗어나지 않음
- 건물 간판 버튼이 해당 건물을 가리지 않음
- 식사 기록 버튼이 캐릭터와 겹치지 않음
- 하단 내비게이션이 콘텐츠를 가리지 않음

## 테스트 및 검증

각 단계마다 다음 순서로 검증한다.

1. 해당 컴포넌트 집중 테스트
2. 전체 테스트
3. 프로덕션 빌드
4. Vercel Preview 배포
5. 모바일 화면 시각 검증

한 단계가 검증되지 않으면 다음 단계로 넘어가지 않는다.

## 비범위

- 새로운 게임 기능 추가
- 라우팅 변경
- 데이터 모델 변경
- 전체 화면을 하나의 이미지로 만드는 방식
- 모든 보조 아이콘의 일괄 3D 자산화

## 성공 기준

- 첫 화면에서 일반 웹앱보다 키즈 게임으로 인식됨
- 로고, 버튼, 아이콘이 동일한 보라·금색 3D 게임 스타일로 통일됨
- 기존 기능과 데이터 흐름이 그대로 동작함
- 작은 모바일 화면에서도 겹침 없이 한 화면에서 사용할 수 있음
